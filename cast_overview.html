Abstract

Personalized text generation aims to infer users' writing style preferences from their historical texts and generate outputs that faithfully reflect these stylistic characteristics. Existing solutions primarily adopt two paradigms: retrieval-augmented generation (RAG) and parameter-efficient fine-tuning (PEFT). While these approaches have advanced the field, they suffer from two critical limitations: (1) the entanglement of content semantics and stylistic patterns in historical texts impedes accurate modeling of user-specific writing preferences; and (2) scalability challenges arising from both RAG's inference latency by retrieval operations and PEFT's parameter storage requirements for per user model. To overcome these limitations, we propose StyleVector, a training-free framework that disentangles and represents personalized writing style as a vector in LLM's activation space, enabling style-steered generation during inference without requiring costly retrieval or parameter storage. Comprehensive experiments demonstrate that our framework achieves a significant 8% relative improvement in personalized generation while reducing storage requirements by 1700 times over PEFT method.

AI Overview

Overview

Personalized text generation represents a critical challenge in making large language models (LLMs) truly adaptive to individual users. While current LLMs excel at generating high-quality text, they lack the ability to tailor their outputs to reflect a user's unique writing style, tone, and preferences. This paper introduces StyleVector, a training-free framework that addresses the fundamental limitations of existing personalized text generation approaches through contrastive activation steering.

The core innovation lies in treating user-specific writing style as a directional vector within an LLM's activation space. By leveraging recent advances in activation engineering - which show that high-level concepts can be represented as linear directions in neural networks - the authors develop a method to disentangle writing style from content semantics and efficiently steer text generation during inference.

Problem Statement and Motivation

Current approaches to personalized text generation face two primary limitations that hinder their practical deployment at scale:

Retrieval-Augmented Generation (RAG) methods enhance LLM inputs by retrieving relevant historical texts from a user's profile. However, these approaches suffer from inference latency due to retrieval operations and struggle with the entanglement of content semantics and stylistic patterns in retrieved texts, leading to style dilution.

Parameter-Efficient Fine-Tuning (PEFT) methods customize LLMs by training lightweight, user-specific adapter modules on individual user data. While computationally more efficient than full fine-tuning, PEFT faces significant scalability challenges due to storage requirements for maintaining distinct parameters for each user, making large-scale deployment impractical.

Both approaches fundamentally struggle with the entanglement problem - they cannot effectively separate what a user says (content) from how they say it (style), as they process historical texts as monolithic units where style and content are intertwined.

Methodology

StyleVector operates through three sequential stages that collectively enable efficient style extraction and application:

Stage 1: Generating Style-Agnostic Responses

The framework begins by creating a "neutral" baseline for each historical input-output pair. For every user interaction (xi,yi)(x_i, y_i)(xi​,yi​) in a user's profile PuP_uPu​, where yiy_iyi​ represents the user's authentic response, the system generates a corresponding style-agnostic response y^i\hat{y}_iy^​i​ using a general, non-personalized LLM (Mg)(M_g)(Mg​):

y^i=Mg(xi)\hat{y}_i = M_g(x_i)y^​i​=Mg​(xi​)

This process creates contrasting pairs: the user-authored yiy_iyi​ contains both content semantics and stylistic patterns, while the model-generated y^i\hat{y}_iy^​i​ preserves content semantics but lacks user-specific stylistic preferences.

Stage 2: Extracting Style Vector

The style vector is computed by contrasting the hidden activations of style-authentic and style-agnostic responses within the base LLM. For each historical piece iii, hidden states are extracted from the last token at layer ℓ\ellℓ:

  • Positive Activation: aℓ,p,i=hℓ(xi⊕yi)a_{\ell,p,i} = h_\ell(x_i \oplus y_i)aℓ,p,i​=hℓ​(xi​⊕yi​)
  • Negative Activation: aℓ,n,i=hℓ(xi⊕y^i)a_{\ell,n,i} = h_\ell(x_i \oplus \hat{y}_i)aℓ,n,i​=hℓ​(xi​⊕y^​i​)

where ⊕\oplus⊕ denotes string concatenation.

The user's style vector suℓs_u^\ellsuℓ​ is then derived using one of three strategies, with mean difference proving most effective:

suℓ=1∣Pu∣∑i=1∣Pu∣(aℓ,p,i−aℓ,n,i)s_u^\ell = \frac{1}{|P_u|} \sum_{i=1}^{|P_u|} (a_{\ell,p,i} - a_{\ell,n,i})suℓ​=∣Pu​∣1​i=1∑∣Pu​∣​(aℓ,p,i​−aℓ,n,i​)

This vector represents the average direction in activation space that distinguishes the user's writing style.

During inference, the extracted style vector guides text generation through linear intervention in the hidden state space. At the selected intervention layer ℓ\ellℓ, the scaled style vector is added to hidden states of generated tokens:

hℓ′(x)t=hℓ(x)t+α⋅suℓh'_\ell(x)_t = h_\ell(x)_t + \alpha \cdot s_u^\ellhℓ′​(x)t​=hℓ​(x)t​+α⋅suℓ​

This steering operation requires only a DDD-dimensional vector addition per generated token, resulting in minimal computational overhead and constant-time complexity relative to user history size.

Key Findings

The experimental evaluation demonstrates StyleVector's superiority across multiple dimensions:

Generation Quality: StyleVector consistently outperforms RAG-based and PEFT-based baselines on LaMP and LongLaMP benchmarks, achieving 8% relative improvement on METEOR and 11% relative improvement on ROUGE-L metrics. Unlike baselines that show unstable performance depending on user history length, StyleVector maintains consistent superiority regardless of history size.

Efficiency Advantages: The framework achieves remarkable efficiency gains:

  • Training Time: Requires only preprocessing through forward passes, approximately 1/5th the time of supervised fine-tuning
  • Inference Latency: Maintains constant latency independent of user history size, avoiding retrieval overhead (RAG) and adapter loading delays (PEFT)
  • Storage Space: Reduces storage requirements by approximately 1700x compared to PEFT methods by storing only a single DDD-dimensional vector per user

Optimal Configuration: Analysis reveals that style-controlling activations are primarily located in middle to later layers (around layer 15+ for LLaMA-2-7B), with positive scaling factors effectively guiding generation toward user style while negative values push away from it.

Style Disentanglement: A probing study confirms robust encoding of user-specific stylistic patterns in LLM hidden states, with classification performance (AUC > 0.85) increasing with layer depth. Case studies demonstrate successful capture of subtle stylistic elements like subtitle usage and specific phrasing patterns while maintaining content fidelity.

Contributions and Significance

StyleVector makes several important contributions to personalized text generation:

Scalability Solution: By compressing entire user stylistic profiles into compact vectors and enabling training-free inference, StyleVector removes the primary barrier to large-scale deployment of personalized LLMs, making them practical for millions of users.

Style-Content Disentanglement: The contrastive approach successfully separates stylistic preferences from content semantics, enabling more precise personalization than methods that treat historical texts as monolithic units.

Activation Engineering Application: The work demonstrates how activation engineering principles can address complex real-world tasks, showing that sophisticated linguistic concepts like writing style are linearly encoded in LLM activation spaces and can be directly manipulated.

Interpretability and Control: By representing style as quantifiable vectors, the framework provides interpretable insights into how LLMs encode stylistic information while offering intuitive control mechanisms for steering generation.

The StyleVector framework represents a significant advance toward making personalized AI assistants practically deployable at scale, offering both superior personalization quality and remarkable efficiency gains that address the fundamental challenges limiting current approaches.
