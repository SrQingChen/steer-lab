# CAST (StyleVector) 精读笔记 — arXiv:2503.05213, ACL 2025, 被引33+

## 方法（已从 alphaxiv 确认）
- 对比构造：对用户历史每条 (x_i, y_i)，用非个性化模型 M_g 生成中性回复 ŷ_i
- 正激活 = h(x_i ⊕ y_i)，负激活 = h(x_i ⊕ ŷ_i) —— 内容相同、仅风格异
- 聚合 = 均值差；推理时仅对生成位置加 α·s_u^ℓ
- 层位：LLaMA-2-7B 集中在 layer 15+；指标 METEOR/ROUGE-L；LaMP/LongLaMP
- 主结果：METEOR +8% / ROUGE-L +11%（vs RAG/PEFT）

## 与本项目的关键对照
1. **它的对比对 ≈ 我们的对照消元提取**：正=用户真实回复，负=中性化改写（M_g 生成）
   —— 同一思想家族。差异：它逐条配对不减基线分布；我们加中性基线分布差分。
2. **⚠️ 它的核心指标是 METEOR/ROUGE-L（n-gram 词面重叠）**！
   这是杀手实验的黄金靶点：
   - ROUGE/METEOR 测的是与参考文本的词面重合——个性化生成里参考=用户历史
   - 格式/语域变化对这些指标的影响方向不明，但**词面模仿（含格式词、口头禅）
     会直接推高它们**——它报告的 +8%/+11% 极可能含大量「词面向用户历史漂移」成分
   - 而词面漂移正是我们测过的「格式模仿」机制（时间戳实验同款）+ 走私风险
3. **它没有测内容走私**（页面无 parroting 实验）——我们独有的检验维度
4. **层位 15+（LLaMA-2 的 0.4~0.5 深度）与我们两个模型的最优层位(0.4-0.5)一致**
   —— 跨模型层位规律获得第三方佐证

## 杀手实验设计 v2（按新情报修订）
主检验改为针对 METEOR/ROUGE-L 的三臂：
  A. CAST 原样（复现 +8/11%）
  B. 格式/文体匹配提示对照（无向量）
  C. 随机向量对照（控制注入本身扰动）
  额外 D. 词面分解：把 METEOR/ROUGE-L 的提升拆成
     「功能词/格式 token 重合」vs「实义词重合」——纯统计可做，直击其指标命门
  预测：D 分解中格式词占比高 => 其 +8/11% 有相当部分是词面记账而非风格语义
## 附带收获
- 我们的对照消元提取与 CAST 思想同源但独立提出——论文中必须诚实引用并
  强调差异（基线分布差分 + 失效边界系统对照 + 效应分解，它们都没有）
