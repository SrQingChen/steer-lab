# 成果占位核查（成文前验证，2026-09-05）

## 逐项裁决

### 1. 「内容解耦的转向向量可转移个人风格」——概念层已被占位 ⚠️
- **CAST**（ACL 2025, arXiv:2503.05213, 被引33+）：从用户历史文本做对比转向，
  以内容-风格解耦为设计目标，training-free，个性化文本生成任务
- **SteerX**（arXiv:2510.22256, 2025.10）：显式分离 preference-driven 与
  preference-agnostic 成分——方法级解耦，比我们的朴素配对更精细
- **Steerable Chatbots**（arXiv:2505.04260）：转向式个性化控制
- **裁决**：本仓库"突破口"的**概念级主张**（转向可带解耦地转移风格）不能再作为
  首次证明陈述。我们的定位降级为：**角色扮演域的受控复现 + 朴素/消元对照 +
  失效边界**。CAST 是否测过内容走私待精读（网络原因未读正文），但概念占位成立。

### 2. 效应分解（格式逃逸 ~70-80% 主导"被测量的风格转移"）——无占位者 ✅
- 检索明确：无论文组合 format confound 与 steering 风格评估的分解
- **核查后升级**：该发现现在是对整条 CAST/SteerX 评估范式的潜在警示——
  它们的 benchmark/judge 评估可能同样被格式逃逸污染。论文主张应以此为第一贡献。

### 3. 失效边界 + 协议正交性几何诊断——增量幸存 ✅（确认性+诊断）
- 18862 求助信仍是锚；无人做过同管线朴素/消元对照 + 阳性控制 + 协议正交性

### 4. 语义金丝雀 + 潜伏概率哨兵 + 盆地动力学——应用扩展幸存，需引先行工作 ✅⚠️
- **先行工作必须引用**：安全社区的 canary token 实践（高熵串埋入系统提示、
  监控输出；llm-canary / ToxSec 等）
- 我们的增量：语义金丝雀（非字符串）、潜伏概率（分布层而非输出层）、
  盆地进入统计（双峰/温度边缘效应）——无人做过

### 5. 距离定律——方向幸存，有近邻需引用 ✅⚠️
- SillyTavern World Info 已用 embedding 相似度按话题邻近度**插入**设定
  （同一思想的反向应用：它用邻近度决定加什么上下文，我们用它预测漏什么）
- 嵌入式注入检测（arXiv:2410.22284 等）是方法近邻

### 6. 回弹协议 / 格式三定律 / 生产现象量化——幸存 ✅（工程与民俗知识的系统化）

## 论文主张重定位（骨架 v1 的修订指令）
第 5 章从《突破口》降格重写为《受控分解与重定位》：
  主贡献 = 效应分解警告（对转向风格评估范式的普遍警示，含对 CAST/SteerX 的适用性讨论）
  次贡献 = 失效边界 + 几何诊断 + 角色扮演域复现
  CAST/SteerX/Steerable Chatbots 进相关工作并诚实对比

## 补充核查（2026-09-05 第二轮）

- CAST实验模型确认：Llama-2-7B-chat（杀手实验可直接复现）
- 新近邻：Evaluating Style-Personalized Text Generation（EMNLP 2026, arXiv:2508.06374）
  批判度量本身，推荐度量集成——未做因果分解、未碰格式逃逸。
  我方定位：因果补全 + 反例证据（DS/GLM/E三家同时被格式骗=集成不治格式混淆，

- 规模依赖性：混淆结构规模不变，幅度未知；1.7B/3B/7B三点可连曲线
